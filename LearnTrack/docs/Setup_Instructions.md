# Setup Instructions

## Software Requirements

- JDK 21 (or your installed JDK version)
- IntelliJ IDEA Community Edition
- Git
- GitHub Account

---

## Verify Java Installation

Open Command Prompt or Terminal and run:

```bash
java -version
```

Example Output

```
java version "21"
```

---

## Clone Repository

```bash
git clone https://github.com/DemigodTrigo/LearnTrack.git
```

---

## Open Project

Open IntelliJ IDEA

File → Open

Select the LearnTrack project folder.

---

## Configure JDK

Go to:

File → Project Structure → Project

Choose your installed JDK.

---

## Run the Project

Navigate to:

```
Main.java
```

Click the Run button.

---

## Hello World Verification

```java
public class Main {

    public static void main(String[] args) {

        System.out.println("Hello World");

    }

}
```

If "Hello World" prints successfully, Java has been configured correctly.
